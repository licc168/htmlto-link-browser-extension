# 中文商店说明

贴到 Chrome 网上应用店后台的 `zh_CN` 语言（同时可用于 Microsoft Edge Add-ons 商店）。

> **后台必改操作清单**：
> 1. **类别（Category）**：当前公开页是「工具 / Extension Tools」，请在后台务必改为 **「效率工具 / Productivity」**。
> 2. **多语言清单**：请同步将 `_locales` 新增的 6 种语言（`zh_TW`、`ja`、`ko`、`es`、`de`、`fr`）后台商店文案贴入（见 `../aso-multilingual.md`）。
> 3. **Edge 商店**：将打包生成的 `dist/htmlto-link-extension.zip` 原样同步提交到 Microsoft Edge Add-ons，方便国内用户免梯安装与自动更新。

```
HTML转URL — 一键把 AI 对话与 HTML 网页转链接
```

## 简短描述（最多 132 个字符）

```
一键将 AI 对话、HTML 网页代码或 Markdown 文档生成可打开的网页链接，支持多种排版模板与实时预览。
```

57 个字符。

## 详细描述

```
HTML转URL（htmlto.link / htmlto.cn）可以把一整段 AI 对话、AI 生成的 HTML 网页代码或 Markdown 文档，一键变成任何人都能直接打开的网页链接。

✨ 适用场景
支持常见网页端 AI 对话与代码生成工具，同时支持本地打开的 HTML 文件（file://）与本地开发预览页面（localhost）。

🚀 核心功能
1. 一键发布整段 AI 对话为精美网页：
   - 点开右上角悬浮胶囊即可勾选需要保留的对话消息（不想导出时默认折叠，不打扰日常对话）。
   - 支持 30+ 排版模板与主题预览，自带目录大纲与数学公式渲染。
   - 也支持一键复制整段对话为 Markdown。
2. 代码块直接生成线上网页链接：
   - 当 AI 输出 HTML / SVG / Markdown 代码块时，直接点击代码块右上角「生成 HTML 链接」或「生成 Markdown 链接」，自动部署并复制可访问 URL。
3. 粘贴代码与本地 HTML 一键托管：
   - 点击浏览器工具栏扩展图标，直接粘贴 HTML / Markdown 代码发布；
   - 打开本地 file:// 或 localhost HTML 页面时，可一键捕获并发布上线。

🔒 隐私与低打扰承诺
- 仅在你主动点击「发布」或「预览」时才会读取并上传你选中的内容到 https://htmlto.link（或中国区 https://htmlto.cn）。
- 绝不在后台静默读取或上传任何对话记录。
- 支持一键隐藏代码块注入按钮，仅通过弹窗或折叠面板按需使用。

未登录时匿名链接约 24 小时后自动失效；登录官网账号即可长期保存与管理（免费/会员均可在网页端管理）。

官网：https://htmlto.link（中国大陆用户支持自动同步 https://htmlto.cn 登录态）
```
