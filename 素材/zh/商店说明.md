# 中文商店说明

贴到 Chrome 网上应用店后台的 zh_CN 语言。说明和图片里不要点名具体聊天网站。

## 名称（最多 45 个字符）

```
HTML转URL
```

## 简短描述

```
把网页或一整段 AI 对话变成链接，手机上就能打开。
```

## 详细描述

```
HTML转URL 把一页网页，或一整段 AI 对话，变成一个可以打开的链接。

对话可以直接发成一页。点「发布对话」之前，可以先预览，并选一种页面样式。如果助手写了一段网页代码，就在代码块上点「生成链接」。

使用步骤
1. 安装，并把图标固定到工具栏。
2. 打开要分享的对话。
3. 点「发布对话」，或在网页代码块上点「生成链接」。
4. 链接会复制好，直接发出去。

也可以点工具栏图标，自己粘贴代码再发布。

未登录的链接大约 24 小时后失效。到 htmlto.link 登录后可以保存更久。

隐私
- 只有你点击发布时，网页或对话才会发到 https://htmlto.link
- 不会在后台读取对话
- 可以关掉页面上的按钮，改从弹窗发布

网站：https://htmlto.link
```

## 这个文件夹里的图片

中文截图放到 `截图/`，宣传图放到 `宣传图/`。运行 `npm run promo:zh` 会生成到这两个目录。

建议上传顺序：

1. 对话页上的发布面板
2. 链接已复制
3. 手机打开后的页面
