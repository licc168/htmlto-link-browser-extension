# 商店素材

中英文分开存放。商店说明里不要罗列聊天网站名称。

| 目录 | 内容 |
|---|---|
| `zh/商店说明.md` | 中文名称、短说明、详细描述 |
| `zh/截图/` | 中文截图，1280×800 |
| `zh/宣传图/` | 中文 440×280 和 1400×560 |
| `en/store-listing.md` | 英文名称、短说明、详细描述 |
| `en/screenshots/` | 英文截图 |
| `en/promo/` | 英文宣传图 |
| `shared/icon-128.png` | 商店图标，中英文共用 |

生成图片：在插件目录运行 `npm run promo:zh` 或 `npm run promo:en`。

权限说明（后台填写，不放进用户可见的详细描述）：

| 权限 | 原因 |
|---|---|
| 读取并修改列出的网站 | 在代码块上加「生成链接」，在对话页加「发布对话」。只有点击后才读取内容，可以关掉。 |
| file:// | 仅当打开本地 HTML 并点击「发布此页」。 |
| activeTab | 点击工具栏图标后，发布当前本地 HTML。 |
| scripting | 在你选择发布时读取当前页 HTML。 |
| storage | 保存发布记录，以及页面按钮是否开启。 |
| clipboardWrite | 发布后复制新链接。 |
| htmlto.link | 把页面上传出去，变成公开链接。 |
